# رفيق المسلم · رفيق حفظ القرآن

برنامج مفتوح المصدر لحفظ القرآن الكريم وعبادات اليوم والليلة. يعمل على الآيفون والأندرويد والحاسوب، ويعمل بدون إنترنت بعد التثبيت.

**الموقع:** https://ityoucef-dotcom.github.io/Baqara/

## ما فيه

- **الحفظ:** خطة لكل سورة على قدر طاقتك، ومصحف ملوّن بأحكام التجويد، وتلاوة الحصري المجوّد مع تكرار الآية، وإخفاء الكلمات للتسميع، والمتشابهات، والمراجعة.
- **المصحف والختمة:** قراءة المصحف كاملاً صفحة صفحة، وخطة ختمة بوِرد يومي.
- **الصلاة:** المواقيت حسب المدينة وطريقة الحساب، والأذان بأصوات متعددة، والقبلة، وسجل الصلوات، وصيام التطوع.
- **الأذكار:** الصباح والمساء وما بعد الصلاة والنوم والجمعة والرقية والأدعية من القرآن والسنة، والمسبحة.
- **المحاسبة اليومية:** أعمال اليوم والليلة مع فضل كل عمل.
- **«الآن»:** يقترح ما يُستحب فعله في وقتك (الثلث الأخير، أذكار ما بعد الصلاة، الضحى، الكهف يوم الجمعة…).

## التثبيت

| الجهاز | الطريقة |
|---|---|
| أندرويد (تطبيق) | نزّل `Rafiq.apk` من [صفحة الإصدارات](https://github.com/ityoucef-dotcom/Baqara/releases/tag/android) وافتحه. الأذان يُرفع في وقته ولو كان التطبيق مغلقاً. |
| أندرويد (موقع) | افتح الموقع في Chrome ← القائمة ⋮ ← «تثبيت التطبيق». |
| آيفون | افتح الموقع في Safari ← «مشاركة» ← «إضافة إلى الشاشة الرئيسية». |

## المصادر والأمانة العلمية

- **نص القرآن:** الرسم العثماني من [Tanzil](https://tanzil.net) ومجمع الملك فهد، ونص التجويد من Quran.com. طوبق النص حرفاً حرفاً بين أكثر من مصدر، ولا يجوز تعديله (شرط ترخيص Tanzil: النقل بلا تغيير مع ذكر المصدر).
- **كتب المكتبة:** نصوص كتب شيخ الإسلام ابن تيمية وسير أعلام النبلاء للذهبي من مشروع [OpenITI](https://github.com/OpenITI) (ترخيص CC BY-NC-SA 4.0، للاستعمال غير التجاري مع ذكر المصدر). الملخصات من إعداد المشروع.
- **كتب الحديث:** متون صحيح البخاري وصحيح مسلم وجامع الترمذي من [hadith-api](https://github.com/fawazahmed0/hadith-api)، وأحكام الترمذي للشيخ الألباني كما وردت فيه. زر «الشرح» يفتح بحث الدرر السنية ويحتاج إلى إنترنت.
- **التلاوة:** محمود خليل الحصري (المجوّد) من [EveryAyah](https://everyayah.com).
- **الأذكار:** من «حصن المسلم»، وكل حديث مذكور معه مصدره ودرجته، ولا يُستعمل الضعيف.
- **المواقيت:** خوارزمية PrayTimes، مع طرق الحساب المعتمدة (منها الجزائر ١٨°/١٧°).

## للمطورين

- الموقع كله في `index.html` (يعمل بلا خادم وبلا إطار عمل)، و`sw.js` للعمل بدون إنترنت.
- الإضافات الجديدة في `src/NAME.js` و`src/NAME.css`، وتُدمج بالأمر:
  `python3 tools/inject.py index.html muhasaba islamic android`
  ثم يُحدَّث رقم النسخة في `sw.js`.
- تطبيقا الهاتف (Capacitor) في الفرع `ios-app` داخل المجلد `app/`:
  - أندرويد: `cd app && npm ci && npm run android` ثم `cd android && ./gradlew assembleDebug`
  - iOS: `npm run sync` ثم Xcode.
  - يبني GitHub Actions ملف APK تلقائياً مع كل تعديل.

المساهمات مرحّب بها: افتح Issue أو Pull Request. أي نص شرعي يُضاف يجب أن يُذكر مصدره ودرجته.
