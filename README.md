# رفيق حفظ القرآن

برنامج لحفظ القرآن سورة سورة، بخطة على قدر السورة ومقدار الحفظ اليومي: مصحف ملوّن بأحكام التجويد، تلاوة الحصري المجوّد، أحكام كل مقطع، الأذكار، مواقيت الصلاة، والتسبيح.

افتح الموقع من Safari على الآيفون، ثم «مشاركة» ← «إضافة إلى الشاشة الرئيسية»، وحمّل التلاوات من صفحة «إحصائياتي» ليعمل بدون إنترنت.
